# F1 Race Simulation — Russell's Singapore Redemption

Planning started: July 29, 2026
First commit: August 4, 2026
Author: Moo So

Recreating George Russell's Singapore Grand Prix story through data:
his 2023 last-lap crash and his 2025 win from pole, visualized
side-by-side using real F1 telemetry.

This project is also a hands-on way to practice math and data skills
relevant to machine learning — interpolation, linear algebra, and
statistics — by applying them to real race data rather than
abstract exercises.

## Phase 1: Digital Replay
Pulling lap and telemetry data (FastF1) for both the 2023 and 2025
Singapore GPs, processing it into a comparable format, and animating
both races on a shared track outline.

**Status:** in progress
